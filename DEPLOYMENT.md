# Key of Heaven deployment

## 1. Prepare a repository

Create a private GitHub repository and upload this project. Do not upload `.env`; it is ignored by `.gitignore`.

## 2. Create MySQL

Render hosts the Node web service, but it does not provide a native MySQL database. Create a MySQL 8 database with a provider such as Railway, Aiven or DigitalOcean Managed MySQL.

Select the database supplied by the provider, then run `schema.sql` against it. The schema only creates tables; it does not try to create a database, which keeps it compatible with managed MySQL accounts. Record the provider's host, username, password and database name.

## 3. Deploy on Render

Create a new **Blueprint** from the GitHub repository. Render will read `render.yaml`. The service will receive a public `onrender.com` URL and Render will provide the `PORT` value automatically.

Set these environment variables in the Render service:

- `DB_HOST`: managed MySQL hostname
- `DB_USER`: managed MySQL username
- `DB_PASSWORD`: managed MySQL password
- `DB_NAME`: `key_of_heaven` or the provider's database name
- `NODE_ENV`: `production`
- `SESSION_SECRET`: a long random value, not the local development secret

Render supplies the public `onrender.com` URL automatically. A custom domain is optional.

## 4. Create the first administrator

Create an account through `/pages/signup.html`, then run this once in the production database:

```sql
UPDATE members
SET is_admin = 1
WHERE email = 'your-admin-email@example.com';
```

## 5. Profile-picture storage

The current uploads directory is local to the server. Render's free filesystem is ephemeral, so uploaded profile pictures can disappear after a redeploy or restart. For production, use a persistent Render disk or move profile images to object storage such as Cloudinary or S3-compatible storage.

## 6. APK

The project is already a Progressive Web App. After the Render HTTPS URL is live, open that URL in PWABuilder and generate an Android package. An APK cannot be generated reliably before the app has a public HTTPS origin and a deployed manifest/service worker.

## Security

The local `.env` values must never be committed. Because the database password and session secret were exposed during setup, rotate both before production deployment. Render's `SESSION_SECRET` should be generated by Render or replaced with a new random secret.
